# Personal Project Agent [Nudge]

## User
Indie developers who work with software

## Problem and purpose

Breaks big tasks into small tasks, adds clarity, and maintains context.

## Use cases

1. Create Project
2. Help create small tasks.
3. Ask “Where are we?”
4. Ask “What should I do next?”
5. Log a decision
6. Update project with the conversation

## One-phrase product

An assistant that helps and guides you to really ship things.
